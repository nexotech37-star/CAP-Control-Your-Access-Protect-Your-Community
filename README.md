# CAP-Control-Your-Access-Protect-Your-Community
El proyecto consiste en desarrollar un sistema destinado a mejorar la seguridad y la gestión de accesos en edificios y condominios. La solución permitirá identificar automáticamente a los vehículos de residentes mediante la lectura de sus placas patentes y reconocer a los residentes que ingresen de manera peatonal.
